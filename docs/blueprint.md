# **App Name**: ByteBlitz

## Core Features:

- Live 1v1 Battle Engine: A real-time matchmaking system using WebSockets to pit users of similar ELO against each other in synchronized coding sprints.
- Elo Rating & Ranking System: Calculates and updates user rankings (1200-2400+) dynamically using the ELO formula after each competitive battle.
- The Code Execution Sandbox: A secure environment to run and validate user submissions against hidden test cases for Python, C++, Java, and JavaScript.
- AI Logic Debugger tool: A generative AI-powered feature that provides limited 'logical hints' when a user fails a test case during non-rated practice sessions.
- Gamified Competitive Dashboard: Displaying win/loss ratios, current ELO rank, achievement badges, and a live 'Arena' status.
- Persistent Leaderboard Storage: Utilizes a PostgreSQL database to manage complex user statistics, global ranks, and weekly division data.
- Dynamic Battle UI: Real-time visual feedback showing opponent progress, line counts, and execution status during a live match.

## Style Guidelines:

- Primary color is a high-octane Neon Cyan (#1AEEFF) to evoke energy and technological speed. Background is a deep Night Slate (#0D1117) to provide high contrast for midnight coding sessions.
- Accent color is a vibrant Electric Purple (#8A2BE2) for CTA buttons and winning notifications.
- Headline font is 'Space Grotesk' for a computerized, machined aesthetic; body text and interface elements use 'Inter' for maximum readability in data-heavy screens.
- Code font: 'Source Code Pro' used for all problem statements and the integrated code editor.
- Sharp, linear vector icons with glowing filter effects that reflect an esports and competitive gaming motif.
- Side-by-side terminal-style layout for battles, keeping the code editor central while ranking and opponent stats are docked on the sides.
- Sudden neon 'glitch' effects on ranking increases and smooth CSS transitions for live leaderboard shifts.
